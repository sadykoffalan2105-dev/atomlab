# ATOMLAB — презентация для InnoWeek

Две отдельные страницы, три языка (oʻzbek / русский / English), обе работают без интернета.

| Что | Ссылка |
|---|---|
| **«Паук»** — весь ATOMLAB на одном экране | https://sadykoffalan2105-dev.github.io/atomlab/innoweek/spider/ |
| **Слайды** — 16 слайдов | https://sadykoffalan2105-dev.github.io/atomlab/innoweek/ |

## «Паук»

В центре — ядро ATOMLAB, слева 5 веток «что видит ученик» (3D-лаборатория, как образуется вещество, органика,
таблица Менделеева, учебники Kimyo 7–11), справа 5 веток ИИ (учитель, художник, учителю, технологии, чего нет у других);
сверху — проблема, снизу — план. Наведите на ветку — она подсветится; нажмите — откроется карточка с живой сценой
(анимация электронов, 3D-молекула, демо-чат ИИ-учителя, сравнение) или настоящим экраном ATOMLAB.

| Клавиша | Действие |
|---|---|
| → · Пробел · PgDn | следующая ветка (пульт-кликер) |
| ← · PgUp | предыдущая ветка |
| 1 … 0 | сразу ветка №1…10 |
| Esc или клик по пустому месту | назад к схеме |
| F · L · B | полный экран · язык · чёрный экран |

## Слайды

## Перед выступлением (обязательно)

1. Откройте **обе ссылки** с интернетом в Chrome или Edge на компьютере, с которого будете показывать.
2. Подождите, пока вверху справа загорится зелёный значок **«Работает без интернета»** (10–30 секунд).
3. Всё: дальше презентация открывается по той же ссылке и без интернета. Если интернет появится — ошибок не будет.
4. Нажмите **F** — полный экран.

## Управление

| Клавиша | Действие |
|---|---|
| → · Пробел · PgDn | следующий слайд (пульт-кликер тоже работает) |
| ← · PgUp | предыдущий слайд |
| F | полный экран |
| O или Esc | все слайды (быстрый переход) |
| L | язык: oʻz → рус → eng |
| B | чёрный экран (нажмите любую клавишу, чтобы вернуться) |
| P | окно докладчика: заметки к слайду, следующий слайд, таймер |
| ? | подсказка по клавишам |

На телефоне и планшете — листайте пальцем. Ссылка на конкретный слайд: `…/innoweek/#9` (номер слайда).

## Интерактив на слайдах

- **Обложка** — живая 3D-молекула (сахароза, аспирин, глюкоза, глицин), можно крутить мышью.
- **Как образуется вещество** — анимация: электрон натрия переходит к хлору (NaCl), кислород делит электроны с водородом (H₂O).
- **Органика** — 7 молекул с настоящей 3D-геометрией из ATOMLAB (RDKit), крутите мышью.
- **Таблица Менделеева** — наведите или нажмите на любой из 118 элементов; у 28 — настоящие фото.
- **ИИ-учитель** — демо-диалог: водород по учебнику, расчёт, голос на узбекском, картинка.
- **ИИ-художник** — все 4 картинки нарисовал ИИ ATOMLAB на нашем сервере.

## Как поправить текст

Тексты всех слайдов — в `js/i18n.js` (ru / uz / en), заметки докладчика — там же (`NOTES`).
После любой правки пересоберите офлайн-часть (обновит список файлов и версию):

```bash
node scripts/innoweek-build.mjs
```

Проверка локально: `python -m http.server 4890 --directory public/innoweek` → http://localhost:4890
