# QA: лаборатория и синтез

## Перед релизом

```bash
npm run build
npm run validate:learn
```

## Реактор (без запуска)

1. Открыть лабораторию → реактор.
2. Ввести уравнение (например `4 Cr + 4 K + 7 O₂`).
3. **Ожидание:** в центре только атомы реагентов, **нет** 3D-молекулы продукта, **нет** чёрного экрана.
4. Подобрать продукт K₂Cr₂O₇ (каталог или авто-match).
5. **Ожидание:** в панели реактора видны формула/название продукта, в Canvas **по-прежнему нет** молекулы до кнопки запуска.

## Синтез K₂Cr₂O₇ (3× подряд)

1. «Проверить и запустить синтез».
2. Полёт атомов → вспышка → одна молекула (без мигания и remount).
3. Повторить 3 раза подряд без перезагрузки страницы.
4. **Ожидание:** стабильный тёмно-синий фон, без сплошного чёрного прямоугольника.

## Регрессии

- [ ] Нет remount Canvas после успеха (только при потере WebGL).
- [ ] После успеха молекула остаётся; при смене уравнения — сброс settled.
