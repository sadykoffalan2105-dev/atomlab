### Ограничения реактора (важно)

- **Синтез 3D:** только элементы слева → **один** продукт из каталога.
- **Практика (`practice_only`):** обмен, замещение с двумя продуктами, сложные ОВР — балансировка и теория без двойного 3D-синтеза.
- Полноценный обмен `AB + CD → AD + CB` с двумя соединениями слева — **архитектурная доработка** (шаблоны реакций).

## Ключевые уравнения программы

См. `CURRICULUM_REACTIONS` в `schoolInorganicManifest.ts` и полный банк в `schoolReactionBank.ts`.

Примеры по типам из вашего доклада:

- **Соединение:** 2Na + Cl₂ → 2NaCl; CaO + H₂O → Ca(OH)₂
- **Разложение:** CaCO₃ → CaO + CO₂; Cu(OH)₂ → CuO + H₂O
- **Замещение:** Zn + 2HCl → ZnCl₂ + H₂; Fe + CuSO₄ → FeSO₄ + Cu
- **Обмен:** BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl
- **ОВР:** K₂Cr₂O₇ + KI + H₂SO₄; Cl₂ + H₂O → HCl + HClO
- **Катализ:** 2SO₂ + O₂ → 2SO₃ (V₂O₅); 2H₂O₂ → 2H₂O + O₂ (MnO₂)
