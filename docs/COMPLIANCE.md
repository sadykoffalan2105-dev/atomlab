# ATOMLAB · соответствие требованиям Узбекистана (ИИ-учитель)

Документ связывает требования законов и правил Республики Узбекистан с **конкретным кодом** проекта: где требование
выполняется, чем это проверяется и что ещё остаётся решить владельцу. Это техническая карта, а не юридическое заключение:
перед пилотом в школах её должен просмотреть юрист (договор обработки данных, согласия через школу, регистрация юрлица).

Обновлено: октябрь 2026 (ветка «соответствие и честность», nextBuild #5).

## 1. ЗРУ-547 «О персональных данных» и ЗРУ-1125 (изменения): данные

### 1.1. Что сервер ИИ-учителя НЕ хранит

- **Адрес IP.** `brain/http/clientIp.ts`: адрес превращается в HMAC-SHA256 с солью `crypto.randomBytes(32)`, которая
  живёт только в памяти процесса (после перезапуска старые отпечатки ни с чем не сопоставить); в файлы не пишется ни адрес,
  ни отпечаток. Проверки: `server.selftest.mts` — «в журнале диалогов нет адресов и заголовков прокси», «во всём журнале
  знаний — ни одного адреса и ни одной сессии».
- **Номер сессии сайта** (`X-Brain-Session`, случайный id вкладки — `brainSessionId()` в
  `src/learn/brain/remote/brainClient.ts`) нужен только лимитам частоты: в ключе лимитера — HMAC пары «адрес + сессия».
- **Тексты учеников из интернета.** `server.dialogLog` по умолчанию **`'local'`** (`brain/config.ts`, `configVersion` 4):
  журнал `journal/dialogs.jsonl` и события `students/*.jsonl` пишутся только для владельца с самого компьютера сервера
  (проверки качества), ученики через туннель не пишутся (`brain/server.ts`: `noJournal = … || (dialogLog === 'local' && !client.local)`).
  Старый `config.json` с прежним умолчанием `'all'` переводится на `'local'` миграцией v4 (в памяти, файл не меняется).
  На сервере друга `deploy/brain-pc/write-brain-config.ps1` делает ту же замену в файле ДО подъёма `configVersion`
  (иначе мозг счёл бы `'all'` явной правкой); проверка — раздел 5 `scripts/brain/deploy-check.ps1`.
  Если владелец осознанно хочет `'all'` (например, по договору со школой), он пишет в `config.json`
  `"configVersion": 4` и `"server": { "dialogLog": "all" }`.
- **Фото задачи.** `brain/http/photo.ts`, `brain/pipeline/photo.ts`: картинка живёт в памяти запроса, в журнал — только флаг
  `hasImage` (проверка «картинок (base64) в журнале нет» в `photo.selftest.mts`).
- **Голос.** `brain/stt/route.ts` → сайдкар 127.0.0.1:8788: аудио распознаётся в памяти и не сохраняется.
- **Картинки.** `brain/image/journal.ts`: в `journal/images.jsonl` — хеш запроса, не текст; PNG в `C:\ATOMLAB\comfy-out`
  старше часа удаляет задача установщика (задача «ATOMLAB Comfy» и `deploy/brain-pc/update.ps1`).

### 1.2. Сроки хранения (`config.server.retention`, `brain/kb/retention.ts`)

| Данные | Срок | Как |
|---|---|---|
| Записи журнала знаний, пришедшие из диалогов (`kind 'dialog'`, `source 'dialog…'`, тег `from:dialog`, `meta.fromDialog`) | 90 дней в поиске | `Journal.search()` / `Journal.searchable()` и векторный поиск (`brain/pipeline/retrieve.ts`) не возвращают их после срока; файл журнала не меняется (правило append-only) |
| События ученика `students/*.jsonl` | 90 дней в модели ученика | `StudentStore.events()` отбрасывает события старше срока |
| Логи `journal/dialogs.jsonl`, `journal/images.jsonl` | ротация раз в месяц | `rotateLogs()` при старте мозга и раз в 6 ч переименовывает лог прошлого месяца в `journal/archive/<имя>-<ГГГГ-ММ>.jsonl` |
| Архивы логов | 90 дней по последней записи | `npm run brain:logs-retention` (показать) / `-- --apply` (удалить) — запускает владелец |
| Технические логи сервера `C:\ATOMLAB\logs` | 14 дней | `deploy/brain-pc/update.ps1` |
| Журнал знаний `journal/kb-journal.jsonl` | не удаляется | append-only (`brain/kb/storage.ts`); в ротацию не входит никогда: закрытый список `ROTATABLE_LOGS` |

В `brain/**` нет вызовов удаления/усечения (проверка `brain:smoke` «в brain/** нет удаления/усечения файлов»); ротация —
это переименование. Удаление архивов — отдельный скрипт вне мозга (`scripts/brain/logs-retention.mts`), который трогает
только файлы `journal/archive/(dialogs|images)-ГГГГ-ММ*.jsonl`.

### 1.3. «Сообщить об ошибке» (`POST /kb/feedback`, `brain/http/feedback.ts`)

- Публичный путь (без ключа админа), но со строгими лимитами: на ученика 3/мин и 20/сутки, на адрес 30/мин и 300/сутки,
  на весь сервер 3000/сутки; тело ≤ 16 КБ; вопрос ≤ 2000, ответ ≤ 6000, комментарий ≤ 1000 символов — сверх лимита 400,
  лишние поля — 400 (нельзя «подложить» адрес или имя в отдельном поле).
- В журнал знаний (`kind 'feedback'`) уходят только `{question, answer, comment}` и короткие метки (причина, язык, класс,
  маршрут ответа). Ни адреса, ни сессии, ни их отпечатков. Телефоны (+998…, международные) и почта маскируются до записи
  (`maskPersonal`). `kind 'feedback'` не участвует в поиске и не попадает в установочный архив (`scripts/brain/package.mts`).
- Интерфейс (`AnswerReport.tsx`) предупреждает: «Не пишите имя, телефон и другие личные данные».
- Проверки: `server.selftest.mts`, раздел 5 (20 проверок), `brain:smoke` раздел 4, `feedbackClient.selftest.ts`.

### 1.4. На устройстве ученика

- История чата темы — `sessionStorage` вкладки (`LearnAssistantPanel.tsx`, ключ `atomlab-learn-chat-…`), кнопка «Очистить».
- Профиль ученика (уровень, темп) — на устройстве (`src/learn/brain/human/studentProfile.ts`), кнопка «Забыть всё».

### 1.5. Что остаётся решить (не код)

- Трансграничная передача: туннель Tailscale Funnel использует relay-узлы за рубежом. Для пилота — домен и прокси в РУз
  (или узел в ЦОД РУз), регистрация в реестре операторов персональных данных при необходимости.
- Согласия: через школу (родители), шаблон согласия и договор обработки данных с юрлицом проекта.
- Выгрузка «что о сессии хранится» для школы: при `dialogLog: 'local'` для учеников из интернета на сервере не хранится
  ничего, кроме добровольных сообщений об ошибке (не связаны с сессией). Если школа включит `'all'` — понадобится выгрузка
  по `sessionId` (следующий шаг).

## 2. ЗРУ-1115 (использование ИИ): решения — за человеком

- Ответ ИИ — **рекомендация**: подвал чата «Ответ ИИ носит рекомендательный характер · Об ИИ-учителе»
  (`AiAdvisoryNote` в `src/components/learn/teacher/AnswerReport.tsx`, вставлен в `LearnAssistantPanel.tsx`) рядом с
  прежним «ИИ может ошибаться — сверяйтесь с учебником и учителем».
- Проверка домашней работы и баллы от ИИ не уходят в журнал школы автоматически; страница `#/about-ai`, раздел
  «Решения принимает человек». Будущие `/teacher/grade` (nextBuild #4) — с пометкой «рекомендация, подтверждает учитель».
- Канал исправления ошибок: кнопка «Сообщить об ошибке» под каждым ответом → `POST /kb/feedback`; записи видит владелец
  (`GET /kb/stats` → `byKind.feedback`; сами записи — в `journal/kb-journal.jsonl`), правка вносится как `kind 'correction'`
  через `POST /kb/append` (только админ).
- Честная уверенность: `done.confidence`/`confidenceLabel` в ответе мозга, цитата параграфа учебника (`citations`).

## 3. Правила этики применения ИИ (№ 3787): информирование пользователей

- Пользователь знает, что говорит с ИИ: название «ИИ-учитель», метка источника ответа (`BrainChip`), подвал чата.
- Страница `#/about-ai` (`src/pages/AboutAiPage.tsx`, текст — `src/pages/aboutAiContent.ts`, ru/uz/en): что умеет, где
  ошибается, что хранится и сколько, к кому обращаться, на каких законах основаны правила. Любое изменение поведения мозга
  в части данных требует правки этого текста и раздела 1 этого документа.
- Контакт: кнопка «Сообщить об ошибке» и страница обращений проекта (`AI_CONTACT_URL` в `aboutAiContent.ts`, сейчас —
  GitHub Issues; после регистрации юрлица заменить на официальную почту).

## 4. ЗРУ-444 «О гарантиях прав ребёнка»

- Без регистрации, без ФИО, без рекламы и рекламных трекеров.
- Картинки: ученикам по умолчанию выключены (`config.image.students.enabled = false`); включены — только готовые темы своего
  класса ±1 (`brain/image/roles.ts`: `presetsOnly`, `gradeWindow`), свободный текст — только владелец и учитель по ключу;
  классификатор безопасности готовой картинки обязателен (`image.safety.required`), порог для учеников строже (0,3).
- Грубые слова: фиксированная фраза R2 + ответ по сути (`brain/pipeline/moderation.ts`).
- Лимиты частоты на ученика и на адрес (`brain/http/rateLimit.ts`, `config.server.rate`) — защита от перегрузки и злоупотреблений.
- Данные детей не используются для рекламы и не передаются третьим лицам; журналы — см. раздел 1.

## 5. Учебники и авторские права

- Флаг `src/data/textbookAccess.ts`: `mode: 'site-pdf'` (умолчание — как было: PDF из `public/textbooks` во встроенном
  просмотре) или `'official-link'` (`VITE_TEXTBOOK_PDF=official` при сборке): PDF с сайта не открываются, вместо просмотра —
  ссылка на официальную электронную копию (`officialUrl` по классу или `officialPortalUrl`). Пока адреса не вписаны,
  ссылка «Официальная электронная копия» не показывается.
- Решение за владельцем: письменное разрешение РЦО/издательства на републикацию — или переключить флаг, вписать адреса
  официальных копий и убрать файлы из `public/textbooks` (флаг сам файлы не удаляет).
- Корпус мозга построен на тексте учебников; установочный архив сервера берёт только журнал знаний без диалогов и отзывов
  (`scripts/brain/package.mts`). Датасеты дообучения — внутренние, не публикуются.

## 6. Что не меняется этим документом

- Правило владельца об ответе на вопрос «разница органической и неорганической химии» (`brain/pipeline/ownerRule.ts`, R1)
  остаётся как есть — решение владельца.
- Фраза R2 на грубые слова остаётся. Политика «никогда не отвечать „не знаю“» остаётся; честность обеспечивается
  уверенностью ответа, цитатой учебника, подвалом «рекомендательный характер» и кнопкой «Сообщить об ошибке».
