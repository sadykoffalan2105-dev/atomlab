### Цепочки с. 101 (словесные) — в тексте урока, опечатки

* «Карбид кальция → **этен** → бензол…» — из карбида кальция получается **этин** (C₂H₂), он и тримеризуется в бензол.
* «Карбид алюминия → метан → этен → этен → этан → хлорэтан» — повтор «этен → этен»; по смыслу метан → этин → этен → этан.
* «Пропановая кислота → этан → этен → этин → бензол → оксид углерода (IV)» — без исправлений.

## 4. Таблица с. 100 (обобщение классов) — показывать исправленной

В учебнике строки перепутаны: строка «Алкины CₙH₂ₙ» с sp² и 120° — это **алкены**; строка «Арены CₙH₂ₙ₋₂» с H–C≡C–H, sp и 180° — это
**алкины**; у циклоалканов «σC–H, σC–H» — верно σC–C, σC–H, угол в циклопропане 60°, в больших кольцах около 109,5°;
у аренов гибридизация **sp²** (не sp³/sp), единая 6π-система. Длины связей C–C верные: 0,154 (алканы), 0,134 (C=C),
0,120 (C≡C), 0,140 нм (бензол). Характерные реакции: алканы — замещение (радикальное), разложение; алкены, алкины,
диены — присоединение; арены — замещение (и присоединение в жёстких условиях).
