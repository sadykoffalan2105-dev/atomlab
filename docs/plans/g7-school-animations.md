# План: молекулярные анимации всех реакций учебника Kimyo 7

Цель — открыть в книге любую реакцию и увидеть её на молекулярном уровне: школьно, по учебнику и химически верно.
Эталон качества — урок NaCl: символ внутри шара, облака внешнего слоя, переход электронов или общие пары, итоговая
решётка или молекула, без энергетики. Числа ниже посчитаны скриптом `scripts/plan/analyze-g7-reactions.mts`.

## Объём

| Что | Число |
|---|---|
| Карточек реакций в каталоге «Реакции учебника «Kimyo», 7 класс» (`equations-g7.json`) | 182 |
| Уникальных реакций (тот же набор веществ) | 137 |
| Уравнений, которые повторяются в разных параграфах | 27 (они дают 45 лишних карточек) |
| Обратных пар (например, CO₂ + H₂O ⇄ H₂CO₃ и H₂CO₃ → CO₂ + H₂O) | 6 |
| Уравнений в тексте учебника, которых нет в каталоге | 5 |
| **Анимаций сделать** | **142** |

Повтор получает ту же анимацию на каждой карточке: 45 карточек не стоят отдельной работы. Обратная пара использует
тот же движок в обратную сторону, кроме электролиза воды: это отдельный процесс с электродами.

Чаще всего повторяются: CH₄ + 2O₂ ×4, Zn + 2HCl ×4, 2Mg + O₂ ×4, N₂ + O₂ ×4, 2H₂S + 3O₂ ×4, CaO + H₂O ×4, 2H₂O → 2H₂ + O₂ ×4, 3H₂ + N₂ ×3.

Порядок: движок сразу с его реакциями, начиная с E1, потому что он обобщает готовый NaCl. После каждого движка —
лист кадров владельцу. На каждый этап и движок — жёсткий лимит времени, перерасход сразу с отчётом.
Точность: ±10–15 мин на отдельную реакцию или движок, около ±10 % на весь объём. Точнее ±10 мин на 120 часов
обещать нельзя.

## Исполнители и недельный лимит

Замер по этой сессии (модель Opus 5.5, план Max): около 3 ч работы израсходовали 2 % недельного лимита и 10 %
пятичасового. Расчёт ведётся по 0,8–1,0 % недели на час работы одного исполнителя: с ростом контекста расход растёт.

| Состав | Время до готовности | Токенов относительно одного | Недельный лимит |
|---|---|---|---|
| Один исполнитель | ≈ 121 ч | 1× | ≈ 100–120 %, одна–полторы недели |
| Я + 2 агента | ≈ 57 ч | ≈ 1,3× | ≈ 130–155 % |
| Я + 3 агента | ≈ 45 ч | ≈ 1,5× | ≈ 150–180 % |
| Я + 5 агентов | ≈ 35 ч | ≈ 2× | ≈ 200–240 % |

Время не делится ровно на число агентов, по трём причинам. Движки опираются на общий набор. Каждую сцену главный
исполнитель проверяет тестом и кадрами, это примерно 5 мин на реакцию, около 12 ч последовательно. Общие файлы
(реестр сцен, каталог, книга, i18n) правит только он. Больше трёх агентов почти не ускоряют работу и быстро съедают
лимит. Пятичасовой лимит при трёх агентах расходуется примерно на 13 % в час: это терпимо, если не запускать
агентов на максимальном усилии.

Правила для агентов: отдельный worktree на агента, свой набор движков без пересечений; запрещены
`git checkout / reset / stash`, `git add -A` и правка общих файлов; сдача = зелёный тест сцены + лист кадров.

## Химические тонкости, которые показываются честно

* 4Fe + 3O₂ → 2Fe₂O₃: горящая в кислороде проволока даёт Fe₃O₄ (окалину); Fe₂O₃ — медленное окисление.
* P₂O₅ в школе, настоящая молекула P₄O₁₀.
* AlCl₃, FeCl₃, ZnCl₂: связь заметно ковалентная — сказано в пояснении.
* H₂CO₃ и H₂SO₃ существуют только в растворе; большая часть CO₂ остаётся растворённым.
* NH₄OH в школе, на деле NH₃·H₂O.
* Реакции, которых нет в учебнике 7 класса (хлориды металлов, нейтрализация), объясняются по учебнику 8 класса
  с пометкой.
