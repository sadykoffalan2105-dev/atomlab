# Каталог: 200 неорганических веществ — группы «по корням», точные 3D-модели и «Как образуется»

Отбор: `src/data/catalog/catalogTop200.ts` (скрипт `scripts/plan/select-top200.mts`) — первые 200 неорганических веществ
рейтинга школьной значимости (учебники 7–11, выверенные уравнения, банк реакций). Остальные 239 скрыты, но остаются в данных.

## 1. Группы («корни»)
Класс → семейство. Соли и кислоты — по кислотному остатку (корню): хлориды, бромиды, иодиды, фториды, сульфиды, сульфаты,
гидросульфаты, сульфиты, нитраты, нитриты, карбонаты, гидрокарбонаты, фосфаты (+ гидро-, дигидро-), силикаты, хроматы и
дихроматы, перманганаты и манганаты, хлораты / хлориты / гипохлориты, комплексные (алюминаты, цинкаты), кристаллогидраты,
двойные соли. Основания — щёлочи / нерастворимые / амфотерные, NH₃·H₂O. Оксиды — основные / амфотерные / кислотные /
несолеобразующие, пероксиды, смешанные (Fe₃O₄). Бинарные — гидриды, карбиды, нитриды, фосфиды, сульфиды и галогениды
неметаллов. Простые вещества-молекулы (H₂, O₂, O₃, N₂, галогены, S₈, P₄).

## 2. 3D-модели (все 200)
- Корень (кислотный остаток, OH⁻, NH₄⁺) — один шаблон на всё семейство, геометрия из ядра со ссылкой (SO₄²⁻ Td,
  SO₃²⁻ пирамида, NO₃⁻ и CO₃²⁻ плоские треугольники, PO₄³⁻ Td, MnO₄⁻ и CrO₄²⁻ Td, Cr₂O₇²⁻ — два тетраэдра с мостиком, …).
- Соль / щёлочь / основной оксид — формульная единица из ионов (шары Шеннона, заряд в подписи, ионы касаются, без палочек
  между ионами); ковалентные связи — только внутри многоатомных ионов.
- Молекулы (кислоты, оксиды неметаллов, гидриды неметаллов) — VSEPR, длины и углы из ядра, кратность по школьной
  графической формуле.
- Кристаллогидрат — соль + n H₂O у катиона; двойная соль — две формульные единицы.
- Проверка каждого из 200: состав = формуле, сумма зарядов = 0, валентности, геометрия = шаблону/ядру, шары не
  перекрываются, подписи читаются; лист кадров всех 200 — просмотр глазами.

## 3. «Как образуется» (все 200)
Анимация в карточке каталога: **Состав** (частицы по отдельности) → **Заряды / валентности** (ионное: «2·(+1) + (−2) = 0»;
ковалентное: валентности атомов) → **Сборка** (связи по одной; ионы притягиваются без палочек) → **Готово** (тип связи:
ионная / ковалентная полярная / неполярная / смешанная — «ионная между Na⁺ и SO₄²⁻, ковалентная внутри SO₄²⁻»; форма).
Это модель строения («из каких частиц»), а не механизм реакции — так и подписано; способы получения — во вкладке «Получение».
