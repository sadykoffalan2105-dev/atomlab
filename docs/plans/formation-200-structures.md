## Генераторы (story/lattice.ts, SYNTH)

- **антифлюорит**: анионы — ГЦК, катионы — 8 тетраэдрических пустот (катион 4, анион 8).
- **куприт**: O (0 0 0), (½ ½ ½); M (¼ ¼ ¼), (¼ ¾ ¾), (¾ ¼ ¾), (¾ ¾ ¼) — M 2, O 4.
- **сфалерит**: катионы ГЦК, анионы ГЦК + (¼ ¼ ¼) — 4 : 4.
- **вюрцит**: гекс., M (⅓ ⅔ 0), (⅔ ⅓ ½); X (⅓ ⅔ u), (⅔ ⅓ ½+u), u = 0,38 — 4 : 4.
- **CsCl**: катион (½ ½ ½), анион (0 0 0) — 8 : 8.
- **троилит**: подъячейка NiAs (a = a₀/√3, c = c₀/2): M (0 0 0), (0 0 ½); X (⅓ ⅔ ¼), (⅔ ⅓ ¾) — 6 : 6.
- **CdI₂**: гекс. a₁ = (a, 0, 0), a₂ = (−a/2, a√3/2, 0), a₃ = (0, 0, c); M (0 0 0); X (⅓ ⅔ z), (⅔ ⅓ −z) — 6 : 3; у OH⁻ атом H
  направлен от катионов слоя (вдоль c, как в брусите).
- **слоистая MX₃**: CdI₂ с a₀ = a/√3 без M при (i − j) mod 3 = 0 — сотовая сетка M, 6 : 2; z = √(d² − a₀²/3)/c.
- **рутил**: тетрагон., M (0 0 0), (½ ½ ½); X ±(u u 0), ±(½+u ½−u ½), u = 0,305 (CaCl₂ — 0,30, a = (a + b)/2) — 6 : 3.
- **NaCl с гантелями** (пирит, CaC₂, BaO₂, KO₂): генератор nacl, шаблон аниона модели в узлах; у пирита гантели S₂
  повёрнуты по диагоналям куба (Pa3), у типа CaC₂ — параллельны (как в модели).

Масштаб фрагмента — расстояние «катион — ближайший анион» модели (якорь частицы — центр её тяжёлых атомов: O у OH⁻,
N у NH₄⁺, середина гантели). Поворот: узел катиона → катион модели, направление на анион → направление модели, угол
вокруг этой оси подбирается так, чтобы остальные частицы модели легли ближе к узлам своего знака (у слоистых — ось c
ближе к плоскости экрана, слои видны сбоку). Узел каждой частицы модели не рисуется (его показывает модель); узлы,
чьи атомы налегли бы на атомы модели (d < 0,8·(r₁ + r₂)), не рисуются.
