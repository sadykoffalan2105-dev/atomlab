# Органика v2 — переделка раздела #/organic с нуля

Запрос владельца (05.10.2026): «всю органику переделать под новую систему, убрать механику сборки и сделать новую,
„Как образуется“ для органики — синтез, правильно для всех, впервые в мире, удобно».

Карта старой системы: `.tmp/organic-v2/map-*.md` (данные/геометрия, страница/режимы, реакции).

## Что не так сейчас

- «Собрать»: из лотка кликами связывают КАЖДЫЙ атом, включая H (тристеарин — 173 атома), углы крутят кнопками ±5°,
  геометрия после связывания не пересчитывается (скриншот владельца: 2,2-диметилбутан с H на связи C–C).
- 3D строится в браузере эвристикой (`organicLayout.ts`): нет торсий, хиральности; жирные кислоты в транс-форме
  (в природе цис), сахароза сломана (C₁₁H₁₂O₁₁), мальтоза = лактоза, амилоза = целлюлоза, α/β-глюкоза неразличимы.
- «Скелет 2D» — проекция 3D на плоскость, у разветвлённых молекул атомы налезают.
- «Уравнение» — пазл из карточек с зашитыми коэффициентами; «Изомеры» — карточки без структур.
- Синтеза/механизма для органики нет нигде: реактор показывает органику шарами без анимации.

## Новая система

### Данные (офлайн, RDKit — `pip install rdkit`, на сайт не попадает)
- `src/data/organicV2/molecules.json` — 329 молекул (те же id): изомерный SMILES (стереохимия: цис-жирные кислоты,
  D-сахара α/β, связи 1→4/1→6, L-аминокислоты), InChIKey, 3D (ETKDGv3 + MMFF94, лучший из N конформеров),
  2D скелетной формулы, гибридизация, заряды Гастайгера, функциональные группы (SMARTS), кольца, классы по учебнику.
- `src/data/organicV2/reactions.json` — органические реакции Kimyo 10–11 с атомным соответствием (`map`) и списком
  изменений связей (`changes`); маршруты получения (`routes`) и свойства (`uses`) для каждой молекулы.
- Контракт: `src/data/organicV2/types.ts`. Старый интерфейс `OrganicMoleculeDef` и все id сохраняются через адаптер
  (каталог, реактор, учитель, 310 ссылок учебника работают как раньше, но с правильной геометрией).

### Режимы страницы (#/organic, параметры `lesson`, `mode`, `mol`, `challenge`, `chapter`/`section`, `src` — совместимы)
1. **Молекула** — точное 3D (шары-стержни, объём, каркас), настоящая скелетная 2D-формула, развёрнутая структурная
   формула; гибридизация (тетраэдр sp³, плоскость sp², линия sp, π-облака), функциональные группы, δ+/δ−;
   инструменты: расстояние (2 атома), угол (3 атома); вращение вокруг одинарной связи с проекцией Ньюмена и графиком
   энергии (заслонённая/заторможенная).
2. **Конструктор** (вместо «Собрать»): рисуешь только скелет (C и гетероатомы, группы из палитры: –OH, –CHO, –COOH,
   –NH₂, –NO₂, кольца), H дорисовываются сами по валентности; кратность — касанием связи; сразу видны формула, класс,
   название по ИЮПАК (как в учебнике), живое 3D. Задания: «собери по названию», «назови собранное», «найди все изомеры»
   (повторы распознаются: «это тот же 2-метилбутан, просто повёрнут»). Проверка — по канонической форме графа.
3. **Изомеры** — галерея с настоящими структурами (2D + 3D) по формуле, виды изомерии (цепь, положение, межклассовая,
   цис/транс, оптическая) с подсветкой отличий; охота за изомерами — через Конструктор.
4. **Синтез** («Как образуется») — маршруты получения из учебника: 3D-анимация на реальных молекулах по атомному
   соответствию (исходные → реакционный центр → разрыв связей → образование новых → продукты), доска со структурным
   уравнением, условия, страница учебника, фразы учителя; ⏮⏯⏭, скорость, ползунок.
5. **Реакции** — химические свойства вещества (где оно исходное) тем же проигрывателем.
6. **Название** — тесты (19 квизов) + задания, генерируемые из Конструктора.
- `mode=build` → Конструктор, `mode=equation` → Синтез/Реакции урока (310 ссылок учебника), `mode=isomer`, `mode=name`.

## Этапы
1. **Фундамент** (параллельно): данные молекул + адаптер; реакции с атомным соответствием; движок Конструктора
   (канонизация графа, изоморфизм, автодобавление H, школьный намер ИЮПАК RU/EN/UZ, мини-силовое поле для 3D собранного).
2. **Интерфейс**: просмотрщик; Конструктор; проигрыватель синтеза; оболочка страницы, уроки, совместимость, тесты.
3. **Проверка**: геометрия всех 329 (длины/углы/столкновения/стереохимия), кадры всех молекул и всех синтезов,
   ссылки учебника и каталога, телефон; исправления.
