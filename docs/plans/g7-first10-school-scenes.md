## Реакция каждой сцены — по учебнику

| Вещество | Реакция | Где | Химия, которую надо показать честно |
|---|---|---|---|
| H₂O | 2H₂ + O₂ → 2H₂O | 7 кл., § 4.5, с. 95 | ковалентная полярная связь; угол H–O–H 104,5°; у O две неподелённые пары; O₂ в школе O=O (на деле бирадикал — в пояснении) |
| CO₂ | C + O₂ → CO₂ | 7 кл., § 4.5, с. 95 | линейная, 180°; две двойные связи O=C=O; C(IV), O(II); уголь — твёрдый, в сцене один атом C (пояснение) |
| NaCl | готово | 8 кл. «Ионная связь» | в 7 кл. NaCl встречается в NaOH + HCl (с. 142) — в пояснении |
| CO | 2C + O₂ → 2CO | 7 кл., § 2.12, с. 69 (недостаток кислорода) | **тройная связь C≡O** (две обычные + одна донорно-акцепторная), 112,8 пм; в 7 кл. по формуле «валентность C — II» — сказать, что связь на самом деле тройная |
| SO₂ | S + O₂ → SO₂ | 7 кл., § 4.5, с. 95 | угловая, 119,5°, S–O 143,1 пм (ядро); у S неподелённая пара; S(IV) |
| SO₃ | 2SO₂ + O₂ ⇄ 2SO₃ | 7 кл., с. 96; 8 кл. с. 136 (катализатор V₂O₅) | плоский треугольник, 120°; S(VI); реакция обратимая, нужен катализатор |
| NO | N₂ + O₂ → 2NO | 7 кл., § 2.13, с. 71 и с. 95 | разрыв тройной связи N≡N (поэтому нужна молния / 2000 °C); в NO нечётное число электронов — **неспаренный электрон**; N(II) |
| NO₂ | 2NO + O₂ → 2NO₂ | 7 кл., с. 71, 96 | угловая, 134°, неспаренный электрон на N; бурый газ; 2NO₂ ⇄ N₂O₄ (пояснение) |

## Школьный стандарт сцены (для всех)

1. **Шесть шагов, 26–34 с:** исходные вещества (как в учебнике: состояние, цвет) → строение атомов (схема слоёв,
   облака внешнего слоя, неспаренные электроны) → разрыв связей исходных молекул → образование общих пар
   (облака перекрываются, пара встаёт между ядрами; для NaCl — переход электрона) → итоговая молекула
   (форма, угол, структурная формула штрихами = валентность) → итог (уравнение, баланс атомов, наблюдение из учебника).
2. Символ элемента внутри шара; электроны внешнего слоя считаются глазами; общая пара — две точки между ядрами,
   неподелённая пара — две точки у атома.
3. Длины связей и углы — только из научного ядра (`src/chemistry/data/bondData.ts`) или справочника с источником.
   В ядре сейчас есть O–H, S=O, O=O, H–H, N=O; нет C=O для CO₂ (116,0 пм; в ядре 122 — альдегиды), C≡O (112,8), N≡N (109,8),
   N–N и N–O в N₂O, N–O в NO₂ и N₂O₅ — добавить с источником (NIST CCCBDB).
4. Без энергетических чисел (как NaCl); «выделяется тепло» — словами, если это есть в учебнике.
5. Тест каждой сцены: баланс атомов; сохранение числа валентных электронов; число общих пар = порядку связи;
   геометрия = ядру; числа в текстах = ядру; объекты видны только на своих шагах.
6. Лист кадров каждой сцены — моя проверка глазами по чек-листу химии перед слиянием.
