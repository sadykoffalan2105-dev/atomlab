# 200 основных реакций: реактор «только уравнять» и анимация частиц для каждой

## 1. Отбор 200 реакций
Источник — выверенные уравнения учебников 7–11 (src/data/textbook/equations-g*.json) и банк школьных реакций
(SCHOOL_REACTION_BANK). Рейтинг: сколько раз реакция встречается в учебниках и классах, есть ли в банке, важность типа
(ОГЭ/ЕГЭ). Условия: все вещества — из 200 веществ каталога (catalogTop200) или простые вещества-элементы; реакция
открывается в реакторе; без дублей; покрытие всех типов — соединение, разложение, замещение, обмен (осадок, газ, вода),
нейтрализация, горение, ОВР (металл + кислота, металл + неметалл, электролиз в примечании), качественные реакции.
Файл `src/data/catalog/mainReactions200.ts` + воспроизводимый скрипт `scripts/plan/select-reactions200.mts`.

## 2. Реактор и каталог
- Вкладка «Реакции» каталога — 200 реакций по типам (минималистично), у каждой: «Уравнять в реакторе».
- В реакторе выбор реакции — только из 200. Реакция открывается со всеми веществами и коэффициентами 1: ученику
  остаётся ТОЛЬКО уравнять. Шарики на экране показывают столько частиц, сколько стоит коэффициент, и меняются сразу;
  счёт атомов по элементам виден и подсвечивается при равенстве; после уравнивания — «Запустить синтез».
- Каждая из 200 обязана: собираться в реакторе, иметь единственный минимальный набор коэффициентов, правильные частицы на
  сцене (ионы солей — ионами, молекулы — молекулами).

## 3. Анимация после синтеза (для всех 200, если нет своей школьной сцены)
Шаги: **Исходные** (частицы по коэффициентам) → **Разрыв** (рвутся связи/ионы расходятся; группы, которые сохраняются —
SO₄²⁻, NO₃⁻, OH⁻ … — переходят целиком) → **Перенос электронов** (только если меняются степени окисления: восстановитель
отдаёт e⁻, окислитель принимает; число e⁻ = Σ изменений степеней окисления по уравнению) → **Образование** (новые
ковалентные связи появляются по одной; ионные продукты собираются во фрагмент решётки; газ — улетает, осадок — оседает)
→ **Итог** (уравнение, баланс атомов и электронов, тип реакции). Атомы сохраняются в каждом кадре. Тексты RU/EN/UZ.
