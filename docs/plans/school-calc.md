# Школьный калькулятор Kimyo 7–11 (brain/calc)

Расчётную задачу школьного курса решает детерминированный код «как в учебнике»: школьные Ar (Cu 64, Cl 35,5, S 32 …),
Vm = 22,4 л/моль, Nₐ = 6,02·10²³, F = 96 500 Кл/моль, T₀ = 273 К; оформление «Дано → Найти → Решение → Ответ» на ru/uz/en.
Модель числа не придумывает: итог инструмента идёт в блок «ВЫЧИСЛЕНО ТОЧНО», а перевранный ответ модели сервер чинит
(`reconcileCalcAnswer`).

## Как это подключено

| место | что | строк |
|---|---|---|
| `brain/pipeline/tools.ts` `runTools` | `const sc = runSchoolCalc(text, cmp, lang, kb); if (sc) return [sc]` — первым; задача распознана уверенно → только его расчёт, иначе старые инструменты | 3 + импорт |
| `brain/pipeline/dialogCheck.ts` `selfCheck` после шага (1) | `reconcileCalcAnswer(text, a.tools, a.lang)` + пометка `calc_answer` в fixes | 2 + импорт |

`ToolResult.tool = 'calc:<тип>'`, `numbers` — только итоговые ответы в школьном округлении, `cite` — `[ATOMLAB: расчёт по <§>]`,
если загружена карта программы (строитель A: `kb.curriculum.taskTypes[].introducedIn`), иначе `[ATOMLAB: расчёт]`.

Остаются за старыми инструментами (tools.ts): pH, степени окисления, уравнивание, ΔH по ΔfH, молярная масса без
«относительной» (IUPAC). Пока не реализованы: gas_mixture, equilibrium (Kc), redox_balance (полуреакции), mixture_fraction,
combustion_formula, metal_plate — такие задачи калькулятор не берёт (null), селфтест это проверяет на задачах учебника
(`unsupported: true` — калькулятор обязан промолчать, а не ответить неверно).

## Проверки

- `npm run brain:selftest:calc` (входит в `brain:selftest`): golden 60/60 (ru 39, uz 11, en 10; ответы посчитаны вручную),
  задачи учебников `brain/calc/fixtures/textbook.jsonl` (выверенные + не поддержанные), 12 базовых типов × 500 случайных задач
  (ru/uz/en, сид) — 100 %, негатив 40/40, сверка ответа 12/12, p95 ≤ 5 мс.
- `npm run brain:eval -- --inproc --cat=calc` и `-- --mock-llm --cat=calc` — 100 % (старые ca01–ca21 + cs01–cs32).
- `npm run brain:calc-mine` — сырые «Пример … Ответ:» из корпусов учебников (checked:false, только отчёт); выверенные
  вручную строки (checked:true) скрипт не перезаписывает.
- Живая проверка на сервере: `npx tsx scripts/brain/calc-live.mts --url=http://<сервер>:8787` — 10 задач Kimyo 8 §1/§25/§26 и
  Kimyo 11 §16/§32 с паузой 8 с (лимит публичного сервера).

## Как добавить тип

1. Решатель в `brain/calc/solvers/*.ts`: `{ id, priority, solve(ctx) }` — сам проверяет, что все величины найдены и роли
   непротиворечивы, иначе `null`. Шаги — функции `(lang) => строка`, ответы — `CalcValue` (число + единица или `text`).
2. Добавить в массив `*_SOLVERS` файла; приоритет: более специфичный — выше.
3. Две золотые задачи в `brain/calc/fixtures/golden.jsonl` (ответ посчитать вручную), при необходимости — генератор в
   `scripts/brain/calc.selftest.mts` и строку `cs…` в конец `brain/eval/questions.jsonl`.
