## 1. Как хранятся задачи и сколько их

**Отдельного датасета с текстами расчётных задач в проекте нет.** Условия задач есть только в PDF и в `lines-gN.json`.

### Что есть в `src/data/textbook/`

**`inventory-g7.json`, `inventory-g8.json`, `inventory-g9.json`** — разбор книги по параграфам.
- Структура: `sections[]` с полями `sectionId, kp, title, pageStart, pageEnd, substances[], reactions[], labWorks[]`; в g8 ещё есть `transformationChains`.
- Схема реакции описана в `inventory-g8.json`, поле `schema.reaction`: `equationAsInBook | equation | reactants/products [{formula, coeff}] | conditions | type | page | quote | balance | bankId…`.
- Полей для расчётных задач (данные, ответ, тип) нет.

**`curated/g7.json`, `curated/g8.json`, `curated/g9.json`** — уравнения, выписанные вручную.
- Пример записи: `{"page":13,"eq":"Ca + 2H2O -> Ca(OH)2 + H2","type":"substitution","cond":"…"}`.
- У заданий книги стоят `exercise:true` и `book:"задание 1: …"`.
- Заданий на уравнения, а не на расчёт: g7 — 42 из 185 реакций, g8 — 81 из 298, g9 — 91 из 482.

**`equations-g7.json`, `equations-g8.json`, `equations-g9.json`** — данные для читалки учебника.
- Собираются скриптом `scripts/textbook-inventory/build-book-reader.mts`, тип — `bookReader.ts:31-53` (`ReaderReaction`: `id, page, equation, equationAscii, asInBook, exercise, conditions, type, bankId, lab{ok, href}`).
- Ссылка `lab.href` открывает реактор, например `/?reactor=1&reaction=zn-hcl&src=…` или `/?reactor=1&eq=…`.
- Расчётные данные встречаются только в тексте поля `conditions`, например у g8 r4: «пример: 26 г Zn → 0,8 г H2 и 54,4 г ZnCl2».
- Объём: g7 — 65 параграфов, g8 — 45, g9 — 42.

**Лабораторные работы (`labWorks`) в inventory:** g7 — 51, g8 — 15, g9 — 22.
- Пример записи: `{title:"Опыт: определение электрической проводимости…", page:20, kind:"demonstration", substances:[{formula, nameRu}]}`.
