## Задача владельца
«Проверь все 200 реакций и сделай 3D более естественным, настоящим и современным; электронный переход доработай; ничего лишнего; чтобы не выглядело по-старому».

Сделай в таком порядке:
1. **Аудит кадров всех 200** (скриптом, без агентов): для каждой реакции 3 кадра — середина переноса e⁻, образование, итог; листы по 12 реакций; просмотри листы и составь таблицу проблем по категориям (наложения шаров/подписей, обрезка кадром, нечитаемые зрители, пустой центр, лишние элементы, химия: неверная кратность/заряд/число e⁻). Отдельно проверь химию скриптом: сумма отданных e⁻ = принятым, степени окисления по школьным правилам, кратность связей = `schoolBondOrders`, формульные единицы ионных веществ.
2. **Перенос электронов — «настоящий»**: e⁻ как светящиеся частицы с мягким хвостом по дуге Безье от атома-донора к акцептору с плавным ускорением/торможением (easeInOutCubic), вспышка прибытия + «щелчок» чипа степени окисления в момент прибытия, свечение донора гаснет/акцептора разгорается синхронно, волны «×n» для больших коэффициентов — ровной серией без «рывков»; карточка полуреакций подсвечивает текущую строку. Никакого телепорта и наложения e⁻ на подписи.
3. **Современный вид**: материалы атомов и палочек как у 3D-героя каталога (`schoolHeroModel`/`naclLatticeView`: матовая поверхность с мягким rim, без пластикового блеска), мягкий свет между камерой и сценой, лёгкое «дыхание» частиц, плавные переходы между шагами (атомы движутся по сглаженным траекториям, палочки проявляются/растворяются, а не появляются мгновенно), спокойная цветовая палитра подписей, одна легенда. Ничего лишнего: убрать дубли подписей, уменьшить количество одновременно видимых чипов/надписей на телефоне.
4. **Огромные реакции** (компактный вид > 40 атомов — mr172, mr177, mr178 и др.): тёмная «стопка» копий позади всё ещё выглядит кучей — сделать одну лицевую копию и аккуратный значок «×n» (или призрачный ряд из 2 копий с сильным затуханием), кадр по центру, камера `fitStageToView` держит всё в кадре на телефоне (ширина 390 px) и десктопе.
5. **Раскладка**: Cr₂(SO₄)₃ и подобные — ионы не теснятся; подписи не перекрывают шары (есть `labelLayout.ts` с разведением подписей); центральный маленький катион виден (уже сделано для FeCl₃/Fe(OH)₃ — проверь остальные).
6. После каждого блока — тесты (оба) и `tsc`; в конце — `npx vite build`, push в `main`, листы «до/после» для 6–8 реакций и короткий отчёт: что исправлено, метрики аудита до/после, что осталось.
