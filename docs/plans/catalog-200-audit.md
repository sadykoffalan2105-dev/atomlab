# Аудит каталога 200 неорганических веществ

Скрипт: `scripts/audit-catalog-200-rules.mts`. Проверяет 200 веществ каталога (`CATALOG_TOP200_IDS`) так, как их
проверял бы строгий рецензент-химик по учебникам Kimyo 7–9.

## Как запускать

```
npm run audit:catalog-200                                # таблица «правило | нарушений | примеры»
npx tsx scripts/audit-catalog-200-rules.mts --list       # все замечания построчно
npx tsx scripts/audit-catalog-200-rules.mts --dump       # карточки для чтения глазами → .tmp/audit200/cards.txt
npx tsx scripts/audit-catalog-200-rules.mts --json       # машинный отчёт → .tmp/audit200/audit.json
```

Код выхода 1, если есть нарушения в любом правиле, кроме информационного d3. Для d3 нужен кэш текста учебников
`scripts/kb/.cache/lines-g7…g9.json`: его ищут в worktree, потом в основном репозитории (`ATOMLAB_MAIN_REPO`).

Вместе с аудитом запускать:
`npx tsc -p tsconfig.app.json --noEmit`, `npx tsc -p tsconfig.node.json --noEmit`, `npm run test:catalog-200-models`,
`npm run verify:catalog200`, `npm run test:catalog-textbook-substances`, `npx tsx scripts/audit-formation-200.mts`.
Если менялся `src/chemistry/formationScripts.ts`, ещё `npm run test:formation-plan`.

## Что проверяет аудит

| f1 | каждое уравнение получения (`obtainingStepsRu`) уравнено |

| g1 | `descriptionRu` не пустой, не шаблонный, не короче 60 символов и не повторяет описание другого вещества. EN/UZ-описания из `compoundDescriptionResolver` — не общий fallback |
| g2 | цвет и агрегатное состояние в описании совпадают с учебником (таблица ожиданий: CuSO₄ безводный — белый, Fe(OH)₃ — бурый …) |

## Что оставлено и почему

- **d3, 29 замечаний (info).** Эти вещества учебник называет только формулой или вообще не называет:
  Mg(OH)₂, MgSO₄, MnSO₄, Li₂O, MnCl₂, PbS, LiOH, Cl₂O₇, Zn(NO₃)₂, CS₂, K₂O₂, AuCl₃, AgI, Ag₂O, CrCl₃, PbI₂,
  Ca(H₂PO₄)₂, CaSiO₃, CaHPO₄, PbCl₂, NaAlO₂, Fe(NO₃)₂, (NH₄)₂CO₃, KClO, H₄P₂O₇, KO₂, Na₂[Zn(OH)₄], Mg₃(PO₄)₂.
  Сюда же относится HMnO₄ (см. выше). Имена этих веществ систематические, по правилам d1, поэтому не менялись.
- **tb_ko2.** Kimyo 9 называет KO₂ просто «пероксидом» («пероксиды Na₂O₂ и KO₂ (или K₂O₄)»). В каталоге оставлено
  химически точное «Надпероксид калия»: анион O₂⁻, с.о. кислорода −½.
- **tb_n2o4.** Название из Kimyo 8 «диоксид азота — N₂O₄» не взято: «диоксид азота» — это NO₂.
- **RU-имена со скобками** («Оксид углерода(IV) (углекислый газ)», «Сульфид меди(I) (медный блеск)») оставлены, как их
  задал предшественник. Правило d1 их допускает: главная часть — учебная, тривиальная стоит в скобках. Правило
  «чистого» имени без скобок (d2) относится только к UZ-именам оксидов и оснований.
- **Апострофы в старых UZ-описаниях `MANUAL_DESC`.** Там стоит ASCII `'` (`o\'g\'it`). Это не трогалось: такая
  правка не входит в аудит. Новые 47 описаний написаны с «‘».
