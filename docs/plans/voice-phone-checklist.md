# Голос ИИ-учителя: ручная проверка на устройствах

Заполняется руками после выкладки site-voice и server-stt. Перед проверкой: открыть урок, «ИИ-учитель» →
«Начать онлайн-диалог» → «Начать урок». Отладочные поля — добавить `?debugVoice=1` к адресу; экран проверки
микрофона — `#/voice-check` (кнопка «Скопировать отчёт» даёт JSON — приложить к замечанию).

Лампы: «Микрофон слышит» (зелёная — громкость речи, серая — тишина, красная — дорожка пропала/запрещена),
«Распознаю» (зелёная — путь жив, жёлтая — 8 с речи без текста). Чип пути: «сервер ATOMLAB» / «браузер» / «нет».

Колонка «Факт»: ✓ / ✗ + коротко, что видно (и JSON «Скопировать отчёт», если ✗).
