# Карта программы Kimyo 7–11

Единый машиночитаемый «скелет» школьной программы Узбекистана по химии — 247 печатных единиц учебников
Kimyo 7–11 (65 тем 7 кл., 45 § 8 кл., 42 § 9 кл., 62 темы 10 кл., 33 § 11 кл., из них 2 — «Практические работы»).
Карта — источник правды для поиска мозга (§-карточка, ссылка на §, подписи цитат), калькулятора задач (типы задач → §)
и генератора контрольных вопросов.

| Что | Где |
|---|---|
| данные | `src/data/kb/curriculum/kimyo-map.json` (≈ 3 МБ, по строке на единицу) |
| схема | `src/data/kb/curriculum/kimyo-map.schema.json`, TS-типы `brain/curriculum/types.ts` |
| типы задач (32) | `src/data/kb/curriculum/task-types.json` — правится вручную (контракт с brain/calc и генератором вопросов) |
| генератор | `scripts/brain/build-curriculum-map.mts` → `npm run brain:curriculum-map` (`-- --check` — только сравнить) |
| загрузка в мозг | `brain/curriculum/map.ts` (`Knowledge.curriculum`, `sharedCurriculum()`) |
| ссылка на § | `brain/curriculum/sectionRef.ts` — `parseSectionRef(text, lang)` |
| §-карточка | `brain/curriculum/card.ts` — `unitCard(unit, lang, maxChars, queryTerms?)` |
| поиск | `brain/pipeline/retrieve.ts` — шаг j) в `retrieveV2`, `citationOf` |
| журнал | `brain/kb/corpusBuild.ts` — источник `curriculum` |
| проверки | `npm run brain:selftest:curriculum` (входит в `npm run brain:selftest`) |

## Как пересобрать

```
npm run brain:curriculum-map          # ≈ 1 с, без сети и LLM; повторный запуск — файл без изменений
npm run brain:selftest:curriculum     # 36 проверок: карта, ссылки на §, поиск, подписи, время
npm run brain:corpus -- --only=curriculum   # дописать §-карточки/задачи/определения в журнал (append-only, повтор — 0)
```

Генератор детерминирован: `generatedAt` меняется только когда меняются входы (`sources` — sha1 каждого входа).

## Схема единицы (кратко)

`id` `g8:12` (класс:номер как напечатан: `12`, `2.6`, `lab`) · `kind` paragraph | practical | review | tasks | lab ·
`label` ru «Kimyo 8, §12» / uz «Kimyo 8, 12-§» / en «Kimyo 8, §12» (7 и 10 кл.: «Kimyo 7, гл. 2, тема 6» /
«Kimyo 7, 2-bob, 6-mavzu» / «Kimyo 7, ch. 2, topic 6») · `cite` «[Kimyo 8, §12]» (страницу добавляет поиск) ·
`chapter`, `appSections` (секции приложения), `title` ru/uz/en + `uzSource` i18n | auto | ru, `pages` ·
`concepts` (≤ 12), `definitions` (≤ 10, текст ≤ 420), `laws` (≤ 4), `formulas` (≤ 12), `reactions` (все уравнения книги),
`substances` (≤ 30, инвентарь книги), `tasks.types` / `examples` (условие ≤ 600 + ответ) / `exercises` (≤ 15),
`tests` (≤ 10, ru/uz/en из банков 7–9 кл.), `topics`, `domain`, `level.prereq/next`, `stats.coverageScore`.

`coverageScore = 0,25·[понятия] + 0,25·[определения] + 0,2·[реакции ≥ 1 или практика/повторение/задачи]
+ 0,15·[примеры/упражнения ≥ 1] + 0,15·[тесты ≥ 1 или 10–11 кл.]`.

## Как мозг использует карту

1. **Ссылка на §.** «Что в §25 Kimyo 8?», «8-sinf 12-§ nima haqida», «расскажи параграф 25 за 8 класс», «тема 2.6 7 класс»,
   «Kimyo 7, 2-bob 6-mavzu», «section 12 grade 8» → `parseSectionRef` → фрагменты этого параграфа (итог, определения, текст)
   без проверки темы и §-карточка первой; `scopeUsed = school`. Класс не назван — класс ученика. Такого § нет —
   ничего не добавляется, в результате `sectionRef: {asked: true, found: false}`. «pH 12», «12 г», «8 класс» — не ссылки.
2. **§-карточка.** Школьный вопрос с известным классом (кроме «кто/история», широких, болтовни, «да/повтори»):
   единица — та, где вся тема вопроса в названии, иначе единица лучшего фрагмента учебника класса (cov ≥ 0,5),
   иначе лучшая по понятиям (score ≥ 0,5). Карточка — `items[0]`, `type: summary`, подпись «[Kimyo 8, §18, стр. 74]»;
   на ноутбуке (бюджет < 900 символов) — до 300 символов. Понятия и определения по теме вопроса — первыми.
   Уверенность с карточкой не ниже `thresholds.medium`. В результате — `curriculum: {unitId, cite, viaRef}`.
3. **Подписи.** `citationOf` для источников `Kimyo N` берёт подпись из карты: 7 и 10 кл. «[Kimyo 7, гл. 2, тема 6, стр. 54]»,
   8, 9, 11 кл. «[Kimyo 8, §12, стр. 50]». Старые строки журнала с «[Kimyo 7, §2.6, …]» не правятся — переписывается
   только показ (`fromRecord`). Карты нет — прежний формат.
4. **Журнал.** Источник `curriculum`: §-карточка каждой единицы (`type:curriculum`, `unit:g8:12`), разобранные задачи
   с ответом (`kind: qa`, `type:task`, `task:<тип>`), определения учебника, которых нет в qaBank.

Все потребители работают и без карты (`Knowledge.curriculum = null`, предупреждение в журнале сервера).

## Пробелы (честно)

- **Названия uz 10–11 кл.** В оглавлении приложения (`gradesOutlineUz.ts`) для 10 и 11 кл. лежит копия русского текста,
  поэтому `uzSource: auto` — перевод по глоссарию (kb-glossary, uzGlossary, понятия мозга) только для названий, которые
  переводятся целиком; остальные пока `uzSource: ru` (≈ 80 % единиц 10–11 кл.). 7–9 кл.: ≥ 85 % из i18n.
  Нужен ручной перевод названий § 10–11 кл. в `gradesOutlineUz.ts` — карта подхватит при пересборке.
- **Разобранные примеры с ответом: 70** (цель спецификации — 150). Майнинг идёт по чанкам корпуса kb-corpus-g*.json,
  где часть примеров разорвана OCR или ответ не подписан «Ответ». Точный кеш страниц (`scripts/kb/.cache`, gitignored)
  генератор пока не читает; задачи-опыты `src/data/labTasks` не подключены (модули тянут типы 3D-лаборатории).
  Калькулятору (brain/calc) это не мешает: его фикстуры размечаются вручную.
- **9 кл.:** 30 секций приложения (законы Фарадея, гальванические элементы, избыточный реагент…) в книге отсутствуют —
  у них нет печатного §, карта их не «дотягивает»; покрытие идёт из карточек ATOMLAB и Kimyo 11.
- **Единицы с coverageScore < 0,6:** g7:7.5, g9:38, g10:2.22, g11:17 (0,4); g8:9, g11:8, g11:21 (0,55) — список печатает
  генератор («худшие по покрытию»).
- Тесты есть только для 7–9 кл. (банков 10–11 кл. нет).
