# Учитель ATOMLAB (бесплатно)

## Языки

ИИ-учитель отвечает и озвучивает на **русском**, **английском** и **узбекском** (lotin).

| Язык | Голос Neural | STT |
|------|--------------|-----|
| RU | DmitryNeural | ru-RU |
| EN | GuyNeural | en-US |
| UZ | SardorNeural | uz-UZ |

Переключите язык интерфейса — учитель автоматически отвечает на выбранном языке.

## Режимы

1. **Локальный мозг** (основной) — свой сервер учителя на ПК владельца: `npm run brain:start` →
   `http://127.0.0.1:8787` (контракт v1). Ответы — модель qwen2.5 7b/3b через Ollama + поиск по учебникам Kimyo 7–11,
   данным ATOMLAB и энциклопедии + точные инструменты (расчёты, уравнивание, проверенные способы получения веществ).
   Без Ollama сервер отвечает запасным путём (поиск + расчёты + шаблоны). Подробно — [brain/README.md](../brain/README.md).
2. **Без сервера** — в браузере: FAQ, каталог, конспект §, расчёты. Без интернета.

Сайт (GitHub Pages) сам находит мозг на `127.0.0.1:8787`; если сервер не запущен — работает режим 2.

## Мозг: модели

```bash
ollama pull qwen2.5:7b-instruct
ollama pull qwen2.5:3b-instruct
ollama pull bge-m3
npm run brain:start      # прогрев моделей в фоне: персоны ru → uz → en (brain/config.ts → warmLangs)
npm run brain:eval -- --inproc   # контрольные вопросы без модели
```

Настройки — `atomlab-brain-data/config.json` (пороги, тайм-ауты, длина подсказки `prompt.chatChars`, по умолчанию 600).

## Голос учителя

**Порядок:** десктоп (Electron, локально) → Edge Neural в браузере (Dmitry / Guy / Sardor) → сервер `/api/learn/tts` → голос браузера (Web Speech).

- Русский: буква **ё**, ударения в терминах химии, формулы → слова
- Узбекский: lotin, химические термины по дасrlik
- Темп: чуть быстрее обычного, без «роботизированной» медлительности
