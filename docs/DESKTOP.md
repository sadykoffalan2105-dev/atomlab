# ATOMLAB — приложение для Windows

ATOMLAB можно собрать как **отдельную программу для Windows**: без браузера и без установки Node.js на компьютере ученика.

## Что получится после сборки

В папке `release/` появятся два варианта:

| Файл | Для чего |
|------|----------|
| **ATOMLAB-1.0.0-portable.exe** | Один файл. Скопируйте на флешку или отправьте в Telegram — на другом ПК просто запустите двойным щелчком. Установка не нужна. |
| **ATOMLAB-1.0.0-win-x64.zip** | Архив с папкой программы. Распакуйте на флешку или на диск — внутри `ATOMLAB.exe`. |

Оба варианта работают **офлайн**: лаборатория, каталог, обучение, 3D-модели.

> **ИИ-учитель** в десктоп-версии работает только если при сборке был задан `VITE_LEARN_CHAT_URL` (облачный API). Без него остаётся локальная подсказка и Ollama (если установлена на этом ПК).

## Сборка (на вашем компьютере разработчика)

1. Установите [Node.js](https://nodejs.org/) LTS.
2. В папке проекта:

```bash
npm install
npm run desktop:build
```

Или дважды щёлкните **`build-desktop.bat`**.

Первая сборка скачает Electron (~150 МБ) — это нормально.

## Перенос на другой Windows-ПК

### Через флешку

1. Скопируйте `ATOMLAB-*-portable.exe` **или** распакованную папку из zip на флешку.
2. На другом компьютере вставьте флешку и запустите exe.
3. При первом запуске Windows может спросить «Разрешить приложению…» — нажмите **Да**. Если SmartScreen ругается: «Подробнее» → «Выполнить в любом случае» (файл вы собрали сами).

### Через Telegram

1. Отправьте **portable.exe** или **zip** себе / в чат / канал (лимит файла до 2 ГБ).
2. На другом ПК скачайте файл и запустите.

> Portable.exe весит примерно **150–250 МБ** — это полный Chromium + 3D + все материалы обучения.

## Режим разработки (окно Electron + hot reload)

```bash
npm run electron:dev
```

Или `run-electron-dev.bat`.

## Установщик (опционально)

Если нужен классический установщик с ярлыком в меню «Пуск»:

```bash
npm run desktop:build:installer
```

Файл `.exe` установщика тоже появится в `release/`.

## Системные требования

- Windows 10 / 11, 64-bit
- Видеокарта с поддержкой WebGL (для 3D)
- ~500 МБ свободного места (portable создаёт временную распаковку при запуске)
