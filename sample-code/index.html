ИИ-учитель в лаборатории

Фрагмент учебного интерфейса: озвучка синтеза диоксида хлора. Учитель объясняет перенос электрона во время реакции и коротко подводит итог после неё.

2 NaClO₂ + Cl₂ → 2 NaCl + 2 ClO₂

Реплики учителя (сценарий ClO₂)

intro — Начинаем
Сейчас получим диоксид хлора. Смотрите на степени окисления хлора.
tension — Сближение
Хлор подходит. Связь в молекуле натягивается.
transfer — Перенос
Перенос электрона из хлорита. Плюс три стало плюс четыре.
Cl в хлорите: +3 → +4
break — Разрыв
Связь порвалась. Хлор принял электрон — минус один.
Cl₂: 0 → −1
pairA — Хлорид натрия
Ион хлора с натрием. Образуется соль.
radicalA — Диоксид хлора
Это диоксид хлора. Угол связей — сто семнадцать градусов.
precipitate / birth — без речи
После реакции только картинка и звук.
complete — Итог
Итог: хлорит окислился, хлор восстановился.
